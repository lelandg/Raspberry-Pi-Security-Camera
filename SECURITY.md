# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- **On GitHub:** open this repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can see the report.
- **By email:** security@chameleonlabs.ai

Tell us what you found, how to reproduce it, and which version or commit you tested. A proof of concept helps, so attach one if you have it.

## What happens next

We'll reply as soon as we can, usually within a week, and keep you posted while we work on a fix. Unless you'd rather stay anonymous, we'll credit you when the fix ships. Please give us a reasonable amount of time to fix the problem before you disclose it publicly.

## Supported versions

Security fixes go into the latest version on the default branch. Older releases don't get backported fixes.

More on how we handle security: <https://chameleonlabs.ai/security>
